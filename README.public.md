# chat-bot

面向 Windows、macOS 与 Linux 的 QQ 聊天助手，复用 React 管理台，使用 Electron 独立窗口与托盘。首版免费非商业使用。

聊天、图片与文件理解、语音及图片发送、长期记忆、联系人审批、QQ 空间发布沿用现有 Antigravity 与 NapCat 接入。账号由每位使用者自行登录，不提供或分享他人的登录凭据。

## 安装与首次使用

首版目标为 Windows 10/11 x64、macOS 13.5 及以上 Intel/Apple Silicon、Ubuntu 24.04 x64。Windows ARM64 留待后续。

Windows 安装向导支持自定义程序安装目录。更换程序目录会保留原有配置和聊天数据。

安装后按应用引导下载并校验组件，设置管理密码和机器人 QQ 号，在官方流程中完成模型登录，在连接与诊断中启动 QQ 并扫码。macOS 需先安装 QQ 到应用程序目录，并在官方 NapCat 安装器中完成授权。Ubuntu 的 QQ 接入需安装 `xvfb` 和 `xauth`。

从旧脚本切换前，先停止同账号的旧桥接及外部定时任务；不会自动导入原项目的私人数据。开发者首次推送公开源码前，运行 `git config core.hooksPath .githooks`，执行本地脱敏与 GitGuardian 门禁，不能等源码上传后才补查。

初始保持干跑，用户设置回复范围并开启真实发送后才发送消息。关闭窗口会缩到托盘，完整退出使用菜单中的退出操作。正常退出前正在运行的实例会在下次启动恢复；人工暂停、崩溃或发送不明不会自动恢复。

QQ 空间开启后，桌面应用每天北京时间18:00触发一次，仅在应用运行且机器人未暂停时执行；错过、失败及结果不明都不自动补发。启用前关闭同账号的其他定时发布任务。

## 开发与构建

源码部署须先将 `.env.example` 复制为配置目录中的 `.env` 并在本机填写 `ONEBOT_ACCESS_TOKEN`。进程环境优先于 `.env`；应用 JSON 不再保存令牌。旧配置迁移、资源授权与当前上传阻塞见 [公开源码审查](docs/PUBLIC_SOURCE_AUDIT.md)。

```sh
npm ci
npm ci --prefix desktop-app
npm test
npm run desktop:pack
```

后端使用独立 Node 24，不依赖开发机预装 Node；打包时从官方来源下载并校验运行时。各平台需要在对应环境构建，安装包位于 `artifacts/desktop`。详细行为与验收流程见 [桌面应用说明](docs/DESKTOP_APP.md)。

## 发布检查

公开源码与内测包、正式安装包、更新源，每次上传前都必须完成隐私复核和 GitGuardian 扫描。检查真名、私人邮箱、电脑用户名、真实测试记录、API Key，以及 Git 作者身份、截图和文件元数据。自动扫描无法替代语义与视觉复核。

`GITGUARDIAN_API_KEY` 仅放入发布环境或 GitHub Secrets。扫描凭据缺失、扫描错误、检测命中、解包失败或扫描覆盖不完整，一律阻止上传与发布。原始扫描报告不进入公共日志和构建产物。GitGuardian 会将候选文本发送到其 API，先完成本地隐私筛查再执行远端检测。
